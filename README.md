# Respaldo Quipux - ESPE

Herramienta de automatización para descargar documentos y anexos del sistema Quipux.

## 📋 Instrucciones de Uso

Para obtener instrucciones detalladas sobre la instalación y el uso de la aplicación, consulta el archivo:

👉 **[MANUAL_DE_USO.md](./MANUAL_DE_USO.md)**

---
### 🛠️ Instalación Rápida

1.  **Instalar dependencias**:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Instalar navegador**:
    ```bash
    playwright install chromium
    ```

3.  **Ejecutar**:
    ```bash
    python bot_quipux.py
    ```
